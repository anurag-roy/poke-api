# Hono

Lightweight web framework used for the Worker. Project was scaffolded with `create-cloudflare` using the [Hono Cloudflare Workers starter](https://github.com/honojs/starter).

- JSX for the homepage: `jsxImportSource` = `hono/jsx` ([`tsconfig.json`](../../tsconfig.json))
- CORS middleware: `hono/cors`
- App typed with `CloudflareBindings` from `wrangler types`
